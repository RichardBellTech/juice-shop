# Controlled Security Exception — ZAP Rule 10038

## Rule
10038 — Content Security Policy (CSP) Header Not Set

## URL Scope
http://127.0.0.1:3000/

This exception applies only to the isolated CPS 5981 classroom Juice Shop lab environment.

## Evidence
The manual response-header review confirmed that the tested root response did not contain a Content-Security-Policy header.

The enforced ZAP baseline run also reported:

FAIL-NEW: Content Security Policy (CSP) Header Not Set [10038]

The enforcement run produced:
- FAIL-NEW: 1
- WARN-NEW: 10
- PASS: 59
- IGNORE: 0

## Reason for Exception
Remediating the upstream OWASP Juice Shop application is outside the intended scope of this lab exercise. The application is intentionally vulnerable and is being used only as an authorized local security-testing target.

## Compensating Controls
- The target runs only as a temporary local container inside GitHub Actions.
- The target is bound to 127.0.0.1:3000 within the workflow environment.
- No production, employer, school, or third-party system is scanned.
- No real customer or sensitive production data is used.
- The container is stopped after every workflow run.
- The exception does not authorize use of this configuration in production.

## Expiration
2026-12-21

## Residual Risk
The missing CSP header remains a real security weakness. This exception does not remediate the finding and must not be interpreted as evidence that the application is secure.
